# Запуск

Требуется Node.js 24.19 или новее.

```bash
npm install
npm run dev
```

## Команды

```bash
npm run build    # сборка
npm run preview  # просмотр сборки
npm run check    # линтеры, форматирование и сборка
npm run fix      # исправление стилей и форматирования
```
