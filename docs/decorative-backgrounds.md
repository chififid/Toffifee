# Декоративные растровые фоны

Эта инструкция обязательна для hero, лиственных цепочек вокруг слайдеров и новых составных растровых фонов.

## Источники и слои

- Для составных цепочек использовать только `src/assets/images/site-foliage/foliage-blue.png`.
- `src/assets/images/footer/footer-fern.png` — самостоятельный экспорт футера. Не использовать его как сегмент цепочки и не добавлять CSS-opacity.
- Общие свойства слоя, crop-рамки, естественного изображения и масок брать из `src/scss/_decorative-background.scss`.
- Фон, сетка и контент должны оставаться независимыми слоями. Декор не принимает pointer events и не создаёт доступного содержимого.

## Сборка цепочки

1. Поместить каждый сегмент в собственную crop-рамку с естественным соотношением сторон.
2. Стыковать сегменты через перекрывающиеся непрозрачные области; прозрачные края не должны соприкасаться.
3. Скрывать вход и выход направленной маской. Не маскировать дефект `border-radius`, случайным overflow или подложкой контента.
4. Поворот и отражение задавать рамке либо изображению осознанно. После трансформации считать локальными торцами все четыре стороны сегмента.
5. Уникальные координаты и матрицы держать в SCSS конкретной секции; базовые свойства не копировать из общего mixin.

## Обязательный визуальный аудит

1. Временно скрыть смысловой контент секции, оставив фон и crop-рамки.
2. Проверить у каждого сегмента четыре локальных торца, внутренние стыки, начало и конец всей цепочки.
3. Повторить аудит целиком после любой правки, а не только на изменённом краю.
4. Вернуть контент и проверить композицию при 1280 и 1600 px, затем при естественном сжатии страницы.
5. Прямая линия, белая щель, тёмный шов, внезапное окончание листьев или граница crop означают незавершённый фон.
6. После проверки выполнить `npm run check`.
